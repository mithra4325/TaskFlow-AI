Architecture

Django Framework: MVT architecture with ORM models, CSRF protection, form validation, and structured request logging.
Database A (SQL): Relational storage (SQLite locally, PostgreSQL in deployment) for Tasks, FAQs, Error Codes, and Support Tickets.
Database B (MongoDB): Dedicated NoSQL storage for chat session logs and user feedback ratings when configured.
Gemini AI Assistant: Context-grounded assistant with fallbacks for offline and unconfigured states.

Technology Stack

Python 3.14 Django 6.0 Google GenAI SDK SQLite / PostgreSQL PyMongo WhiteNoise Vanilla CSS
